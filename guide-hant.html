基本玩法

  • ♥ 心動值：每位女嘉賓都有自己的心動值。對話、選座位、扔紙飛機都會讓它漲或跌，畫面上會提示「♥ 小滿 心動 +2」。「嘉賓檔案」裡能看到現在的心動值，每集結尾的結算卡會列出這一集誰漲了多少。
  • 🔥 節目熱度：翻車、名場面和上熱搜會讓熱度上漲。每集結算卡會顯示熱度；結局時，熱度換算成全網播放量和節目評級，從 D 到 S。
  • ⏱ 限時抉擇：有些選擇要在幾秒內做決定，倒計時結束會自動選最後一個選項。不想被催，可以在「設定」裡關掉「限時選擇」。
  • 💥 翻車結局：有些選項會讓你當場翻車，比如對 HR 掀桌。翻車不是 Game Over：結局卡上一鍵就能回到上一個選擇。
  • 🌳 劇情回溯：隨時打開「回溯」（快捷鍵 T），跳回這一輪裡的任何一個選擇，換個選項試試。選過的選項會標上「已選過」。
  • ✈️ 紙飛機：每天晚上，可以把寫著心裡話的紙飛機扔到一個人的陽臺上，只能扔一架。扔給誰，會影響她的心動值。
  • 💬 彈幕和嘉賓群：觀眾會在彈幕裡起鬨；晚上的嘉賓群聊裡，你的每一條回覆也是一次選擇。
  • 🎮 小遊戲：完整版裡有幾個計時小遊戲，指針進入綠色區域時按下。
  • 💾 存檔：隨時存檔、讀檔（F5 / F9 快速存讀檔），存檔只儲存在當前瀏覽器裡。電腦上的「掃碼用手機玩」可以把進度帶到手機上。
  • 🌐 簡 / 繁和讀屏模式：標題畫面或「設定」裡可以切換繁體中文；視障玩家可以打開讀屏模式。
⚠️ 劇透：結局是怎麼來的（點開檢視）

一共 28 個結局：HAPPY END ×6、TRUE END ×1、遺憾結局 ×6、NORMAL END ×3、翻車結局 ×12。最後一晚在燈塔下告白，成不成，看下面這些：

  • HAPPY END：心動值要夠，還要在後面的約會裡真正走進她的心事，幫她解開心結。
  • 遺憾結局：心動值夠了，心結卻沒有解開時告白，就會走向她的遺憾結局。每位女嘉賓各有一個。
  • NORMAL END：心動值不夠時告白，或者最後誰也不選，都會走向普通結局。
  • 番外「一年以後」：集齊全部 6 個 HAPPY END 後，標題畫面會出現「番外」，那是 TRUE END。
  • 節目評級 S：多選讓節目「出圈」的選項，熱度夠高就是 S。每個 HAPPY END 都拿得到 S。
隱藏路線的提示（更大的劇透）紙飛機，不一定要飛向女嘉賓。

常見問題

有幾個結局？
28 個：HAPPY END ×6、TRUE END ×1、遺憾結局 ×6、NORMAL END ×3、翻車結局 ×12。還有一條隱藏路線。遊戲裡的「結局圖鑑」會列出全部結局，沒解鎖的顯示「？？？」，可以點「顯示提示」。
選錯了能重來嗎？
能。翻車結局不是 Game Over：結局卡上一鍵就能回到上一個選擇。「回溯」（快捷鍵 T）還能跳回這一輪裡的任何一個選擇；已經選過的選項會標上「已選過」。
限時選擇可以關掉嗎？
可以：在「設定」裡關掉「限時選擇」。倒計時結束時，會自動選最後一個選項。讀屏模式也會關掉倒計時。
心動值和節目熱度是什麼？
每位女嘉賓都有自己的心動值，對話、座位和紙飛機都會讓它漲或跌。節目熱度隨翻車、名場面和熱搜上漲，結局時換算成全網播放量和節目評級（D 到 S）。
番外怎麼開啟？
集齊全部 6 個 HAPPY END 後，標題畫面會出現「番外」。
隱藏路線怎麼進？
有提示，但會劇透：見本頁「結局是怎麼來的」（預設摺疊），或者遊戲裡結局圖鑑的「顯示提示」。
免費試玩能玩到哪裡？
序章和第一集，到第一晚的紙飛機為止，大約 15 分鐘。完整版用啟用碼解鎖，試玩進度自動繼承。
