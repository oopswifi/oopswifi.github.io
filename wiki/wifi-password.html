查看已连接 Wi-Fi 的密码iPhone、安卓、Windows、Mac，各几步

手机或电脑只要连过这个 Wi-Fi，就能在它自己的设置里把密码找出来[1][2]。这一页只教你在自己的设备上看：不用、也不要把密码输进任何网页，包括这一页。

iPhone安卓WindowsMac

iPhone / iPad（iOS 16、iPadOS 16.1 及以上）

  1. 打开「设置」，轻点「无线局域网」（Wi-Fi）[1]。
  2. 在正在用的网络旁边，轻点 ⓘ（信息）按钮[1]。
  3. 轻点「密码」，用面容 ID、触控 ID 或锁屏密码解锁，密码就显示出来了[1]。

以前连过、现在没连着的网络：在「无线局域网」里轻点右上角的「编辑」，解锁后找到它，再轻点 ⓘ 和「密码」。iOS 18 还可以在「密码」App 里点「无线局域网」查看[1]。

安卓手机（Android 10 及以上）

  1. 打开「设置」，进入「网络和互联网」›「互联网」[3]。各品牌的叫法和位置不一样，也可能叫「WLAN」或「无线网络」[4][5]。
  2. 轻点正在用的网络，再轻点「分享」，按提示验证锁屏[3][4]。
  3. 屏幕上出现一个二维码，另一台手机扫它就能连上[3]。很多手机会把密码直接写在二维码下面[4][5]。

Windows 电脑

Windows 11

  1. 打开「设置」›「网络和 Internet」›「属性」，在「Wi-Fi 网络密码」旁边选「显示」[2]。
  2. 以前连过的网络：在「管理已知网络」里选中它，再选「Wi-Fi 网络密码」旁边的「显示」[2]。

Windows 10

  1. 打开「设置」›「网络和 Internet」›「状态」›「网络和共享中心」[2]。
  2. 点「连接」旁边的 Wi-Fi 名称，再点「无线属性」[2]。
  3. 打开「安全」选项卡，勾选「显示字符」，密码就在「网络安全密钥」里[2]。

命令行（Windows 11 和 10 都行）

打开「命令提示符」，输入下面这一行（把「网络名」换成 Wi-Fi 的名字），回车：

netsh wlan show profile name="网络名" key=clear

在「安全设置」（英文系统是 Security settings）里，「关键内容」（Key Content）后面就是密码[6][7][8]。

Mac

macOS 13 Ventura 及以上

  1. 从苹果菜单打开「系统设置」，点边栏里的「网络」，再点右边的「Wi-Fi」[9]。
  2. 往下滚，点「高级」，打开已知网络的列表[9]。
  3. 点网络名旁边的「更多」按钮（⋯），选「拷贝密码」，再粘贴到备忘录之类的地方看[9]。

macOS 15 及以上还可以打开「密码」App，点边栏里的「Wi-Fi」，选中网络，把指针放在「密码」那串圆点上[10]。

常见问题

iPhone 怎么看已连接 Wi-Fi 的密码？
iOS 16 及以上：设置 › 无线局域网，轻点网络旁边的 ⓘ，再轻点「密码」，用面容 ID、触控 ID 或锁屏密码解锁。[1]
安卓手机怎么看 Wi-Fi 密码？
Android 10 及以上：在 Wi-Fi 设置里轻点正在用的网络，再轻点「分享」，验证锁屏后会出现二维码；很多手机会把密码写在二维码下面，另一台手机扫码也能直接连上。[3][4]
Windows 电脑怎么看 Wi-Fi 密码？
Windows 11：设置 › 网络和 Internet › 属性，在「Wi-Fi 网络密码」旁边选「显示」。Windows 10：网络和共享中心 › Wi-Fi 名称 › 无线属性 › 安全，勾选「显示字符」。[2]
Mac 怎么看 Wi-Fi 密码？
macOS 13 及以上：系统设置 › 网络 › Wi-Fi › 高级，在网络名旁边的「更多」按钮里选「拷贝密码」，再粘贴出来看。[9]
