后台地址印在路由器底部的标签上，以标签为准[1][2]。下面是几家常见品牌在自家官网写的默认地址：手机或电脑连上这台路由器，在浏览器的地址栏里输入，回车。

后台打不开？按顺序查

  1. 连对了吗？手机或电脑要连着这台路由器的 Wi-Fi，或者用网线插在它的 LAN 口[1][2]。
  2. 输对地方了吗？地址输在浏览器最上面的地址栏里，不是搜索框；字母全小写，点要用英文的「.」[1][8]。
  3. 用手机的话：先暂时关掉移动数据，把浏览器完全退出再打开[10]。
  4. 换一个试试：换个浏览器，或者换台手机、电脑[1]。
  5. 电脑上：把网卡设成「自动获取 IP 地址」[1]。
  6. 最后才复位：路由器通电时，用回形针按住 RESET 键 5～8 秒，等指示灯快闪再松开[1][5]。复位会恢复出厂设置，之后要重新设置上网[4]；拨号上网要重新输入宽带账号和密码，忘了可以问运营商[3]。有的路由器 WPS 键和 RESET 是同一个键[5]。

三个该关掉的开关

动手之前，先把后台的管理密码换掉：出厂的默认密码别人也查得到[11]。有的 TP-LINK 旧款默认是 admin / admin[1]；小米路由器的管理密码默认和 Wi-Fi 密码一样，可以在「高级设置」里分开设[3]。

开关它做什么为什么关
远程管理（有的叫「WAN 口管理」）让人从外网打开、修改路由器的设置用不到就关；关掉不影响家里正常上网[11][12]
WPS（一键连接）按一下按钮或者输 8 位 PIN 码，不用 Wi-Fi 密码就能连上[5][11][13]PIN 码的设计有缺陷，能被暴力破解，拿到 Wi-Fi 密码[13]
UPnP让家里设备上的程序自动在路由器上开端口不需要就关；有的游戏机、P2P 软件要用它，关了连不上可以再开，或者手动设置端口映射[11][12]

TP-LINK 的远程管理一般在「系统设置 → 管理服务」，UPnP 在「高级设置 → 转发规则 → UPnP 设置」；菜单随型号和固件变化，小米和华为的位置见来源里的文章[12]。

常见问题

tplogin.cn 打不开怎么办？
先确认手机或电脑连着这台路由器的 Wi-Fi，或者网线插在 LAN 口；在浏览器地址栏里输入 tplogin.cn（全小写），不行就试 192.168.1.1、换个浏览器；最后才按住 RESET 键 5～8 秒恢复出厂设置。[1]
小米路由器的后台地址是多少？
miwifi.com，或者 192.168.31.1。后台的管理密码默认和 Wi-Fi 密码一样。[3]
华为路由器的后台地址是多少？
192.168.3.1。运营商定制的型号可能不一样，以路由器底部铭牌上的地址为准。[2][4]
路由器的远程管理要不要关？
用不到就关。远程管理让人可以从外网查看和修改路由器的设置；关掉它，不影响家里正常上网。[11][12]
