修網線百科

檢視已連線 Wi-Fi 的密碼iPhone、安卓、Windows、Mac，各幾步

手機或電腦只要連過這個 Wi-Fi，就能在它自己的設定裡把密碼找出來[1][2]。這一頁只教你在自己的設備上看：不用、也不要把密碼輸進任何網頁，包括這一頁。

iPhone安卓WindowsMac

iPhone / iPad（iOS 16、iPadOS 16.1 及以上）

  1. 打開「設定」，輕點「Wi-Fi」[1]。
  2. 在正在用的網路旁邊，輕點 ⓘ（資訊）按鈕[1]。
  3. 輕點「密碼」，用密碼、Face ID 或 Touch ID 解鎖，密碼就顯示出來了[1]。

以前連過、現在沒連著的網路：在「Wi-Fi」裡輕點右上角的「編輯」，解鎖後找到它，再輕點 ⓘ 和「密碼」。iOS 18 還可以在「密碼」App 裡點「Wi-Fi」檢視[1]。

安卓手機（Android 10 及以上）

  1. 打開「設定」，進入「網路和網際網路」›「網際網路」[3]。各品牌的叫法和位置不一樣，也可能叫「WLAN」或「無線網路」[4][5]。
  2. 輕點正在用的網路，再輕點「分享」，按提示驗證鎖屏[3][4]。
  3. 螢幕上出現一個二維碼，另一臺手機掃它就能連上[3]。很多手機會把密碼直接寫在二維碼下面[4][5]。

Windows 電腦

Windows 11

  1. 打開「設定」›「網路和網際網路」›「內容」，在「Wi-Fi 網路密碼」旁邊選「顯示」[2]。
  2. 以前連過的網路：在「管理已知網路」裡選中它，再選「Wi-Fi 網路密碼」旁邊的「顯示」[2]。

Windows 10

  1. 打開「設定」›「網路和網際網路」›「狀態」›「網路和共用中心」[2]。
  2. 點「連線」旁邊的 Wi-Fi 名稱，再點「無線內容」[2]。
  3. 打開「安全性」索引標籤，勾選「顯示字元」，密碼就在「網路安全性金鑰」裡[2]。

命令列（Windows 11 和 10 都行）

打開「命令提示字元」，輸入下面這一行（把「網路名」換成 Wi-Fi 的名字），按 Enter 鍵：

netsh wlan show profile name="網路名" key=clear

在「安全性設定」（英文系統是 Security settings）裡，「金鑰內容」（Key Content）後面就是密碼[6][7][8]。

Mac

macOS 13 Ventura 及以上

  1. 從蘋果選單打開「系統設定」，點側邊欄裡的「網路」，再點右邊的「Wi-Fi」[9]。
  2. 往下滾，點「進階」，打開已知網路的列表[9]。
  3. 點網路名旁邊的「⋯」按鈕，選「複製密碼」，再貼上到備忘錄之類的地方看[9]。

macOS 15 及以上還可以打開「密碼」App，點側邊欄裡的「Wi-Fi」，選中網路，把指標放在「密碼」那串圓點上[10]。

常見問題

iPhone 怎麼看已連線 Wi-Fi 的密碼？
iOS 16 及以上：設定 › Wi-Fi，輕點網路旁邊的 ⓘ，再輕點「密碼」，用密碼、Face ID 或 Touch ID 解鎖。[1]
安卓手機怎麼看 Wi-Fi 密碼？
Android 10 及以上：在 Wi-Fi 設定裡輕點正在用的網路，再輕點「分享」，驗證鎖屏後會出現二維碼；很多手機會把密碼寫在二維碼下面，另一臺手機掃碼也能直接連上。[3][4]
Windows 電腦怎麼看 Wi-Fi 密碼？
Windows 11：設定 › 網路和網際網路 › 內容，在「Wi-Fi 網路密碼」旁邊選「顯示」。Windows 10：網路和共用中心 › Wi-Fi 名稱 › 無線內容 › 安全性，勾選「顯示字元」。[2]
Mac 怎麼看 Wi-Fi 密碼？
macOS 13 及以上：系統設定 › 網路 › Wi-Fi › 進階，在網路名旁邊的「⋯」按鈕裡選「複製密碼」，再貼到別的地方看。[9]
